# Security Policy

## Supported Versions

DeskDangle provides security updates and patches for the following versions:

| Version | Supported          |
| :--- | :--- |
| 2.0.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

---

## Reporting a Vulnerability

Security and privacy are foundational values of DeskDangle.

If you believe you have discovered a security issue, vulnerability, or potential exploit in DeskDangle:

1. **Do not disclose the issue publicly** in a public issue or forum.
2. Please report the issue privately through [GitHub Private Security Advisory](https://github.com/heyriyaz/DeskDangle/security/advisories/new) or by contacting the maintainer via GitHub profile [@heyriyaz](https://github.com/heyriyaz).
3. Include as much information as possible:
   - Operating system and version (Windows 10/11 or macOS)
   - DeskDangle app version
   - Detailed reproduction steps or proof-of-concept
   - Impact assessment

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate and publish a fix.
