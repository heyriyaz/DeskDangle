# Privacy Policy for DeskDangle

**Last updated:** September 2026

DeskDangle ("the Application") is developed by Riyaz as an interactive desktop companion for Windows. This Privacy Policy describes how DeskDangle handles user information.

## 1. No Personal Data Collection
DeskDangle does **not** collect, store, track, transmit, or sell any personal information, identifiable data, telemetry, or browsing history.

## 2. Local-Only Operation & Storage
- All configuration settings (such as charm choices, physics settings, and appearance preferences) are stored strictly locally on your Windows device.
- No data is ever transmitted to external servers, cloud databases, or third-party services.

## 3. Network Usage
DeskDangle is an offline application. It does not require an active internet connection to function and contains no background telemetry or analytics trackers.

## 4. Third-Party Services
The Application does not integrate with any third-party SDKs, analytics platforms, or advertising networks.

## 5. Contact
If you have any questions about this Privacy Policy, please open an issue on GitHub:
https://github.com/heyriyaz/DeskDangle
